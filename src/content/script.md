# スクリプト

スクリプトをオブジェクトに割り当てると、そのオブジェクトの初期化時とシミュレーション中にコードを実行できます。スクリプトの作成・編集は**設定 → データ管理 → スクリプトの管理**から行います。

> このページは現在の実装に基づく仕様です。JavaScript全体を実行できるわけではありません。ここに記載のない構文や機能は利用できません。

## 基本構造

プログラムには`init`ブロックと`update`ブロックを記述できます。両ブロックとも省略できますが、両方記述する場合は`init`を先に置きます。

```js
init {
    speed = 10;
    obj.resource.color = "#ff0000";
}

update {
    obj.position.x += speed;
}
```

- `init`はスクリプトがオブジェクトに初めて実行されるときに呼び出されます。
- `update`はシミュレーション中、**スクリプト実行間隔**に従って繰り返し呼び出されます。
- 停止中に**ステップ**を実行してもスクリプトが更新されます。
- `init`で初期化した状態はオブジェクトごとに保持されます。ワールドのインポートや**グローバル変数をリセット**を行うと状態が消え、次の実行時に再び`init`が呼ばれます。

## オブジェクトと変数

`obj`はスクリプトが割り当てられたオブジェクトです。ドットでプロパティを指定できます。

| オブジェクト | 利用できる主なプロパティ |
|---|---|
| 円 | `obj.position.x` / `.y`、`obj.velocity.x` / `.y`、`obj.diameter`、`obj.mass`、`obj.stiffness`、`obj.resource.color` |
| 直線 | `obj.start.x` / `.y`、`obj.end.x` / `.y`、`obj.width`、`obj.resource.color` |
| 曲線 | `obj.start`、`obj.middle`、`obj.end`の各`.x` / `.y`、`obj.width`、`obj.resource.color` |
| 加速器 | `obj.start.x` / `.y`、`obj.end.x` / `.y`、`obj.velocity.x` / `.y`、`obj.resource.color` |

`init`ブロックで`obj`以外の名前に代入すると、オブジェクトごとの持続状態を作成します。

```js
init {
    elapsed = 0;
}

update {
    elapsed += 1;
    obj.position.x = 100 + 50 * cos(PI * elapsed / 60);
}
```

`init`で代入されていない名前に`update`で代入すると、その変数は更新処理の呼び出しごとに初期化されるローカル変数です。値を次の更新まで保持したい場合は、`init`で先に代入してください。変数の宣言文（`let`など）は不要です。

## 文とコメント

利用できる文は代入、関数呼び出し、`if` / `else`です。各ブロック内には複数の文を記述できます。セミコロンは省略できます。

```js
update {
    if (obj.position.y > 300) {
        obj.velocity.y = -10;
        console("上向きに変更");
    } else {
        obj.velocity.y += 1;
    }
}
```

行コメントには`//`を使います。複数行コメントには対応していません。

```js
// 円が一定の高さに達したら速度を変更する
update {
    if (obj.position.y > 300) {
        obj.velocity.y = -10; // 上向き
    }
}
```

## 式と演算子

数値、文字列、識別子、関数呼び出し、括弧付きの式を使用できます。文字列は**ダブルクォーテーション**で囲みます。

```js
message = "Hello";
value = (10 + 5) * 2;
```

| 分類 | 演算子 | 説明 |
|---|---|---|
| 単項 | `!`、`-` | 論理否定、符号反転 |
| 乗除算 | `*`、`/` | 乗算、除算 |
| 加減算 | `+`、`-` | 加算、減算 |
| 比較 | `<`、`<=`、`>`、`>=` | 数値などの大小比較 |
| 等価比較 | `==`、`!=` | JavaScriptの緩い等価比較 |
| 代入 | `=`、`+=`、`-=`、`*=`、`/=` | 代入、複合代入 |

括弧、単項演算、乗除算、加減算、比較の順に評価されます。乗除算・加減算は左から評価します。1つの比較式に比較演算子を複数連結することはできません。

## 組み込みの値と関数

| 名前 | 内容 |
|---|---|
| `PI` | 円周率（`Math.PI`） |
| `E` | 自然対数の底（`Math.E`） |
| `sin(x)`、`cos(x)` | 三角関数。角度はラジアンです。 |
| `abs(x)` | 絶対値 |
| `max(a, b, ...)`、`min(a, b, ...)` | 最大値、最小値 |
| `console(value)` | ブラウザーの開発者コンソールに出力します。 |
| `find(id)` | 指定IDのオブジェクトを返します。見つからない場合は`null`です。 |
| `exist(id)` | 指定IDのオブジェクトが存在するかを返します。 |
| `distance(a, b)` | 2つの位置ベクトル間の距離を返します。例: `distance(obj.position, target.position)` |
| `destroy(id)` | 指定IDのオブジェクトをワールドから削除します。 |

`find`で取得したオブジェクトも、例えば`find("ball").position.x`のようにプロパティを参照できます。対象オブジェクトが存在するか不明な場合は、`exist(id)`で確認してから操作してください。

## 識別子と制限

- 識別子は`[A-Za-z_][A-Za-z0-9_]*`の形式です。数字から始めることはできません。
- `obj.position.x`のように、ドットでプロパティを連結できます。
- 文字列リテラルはJSON形式のエスケープを含むダブルクォーテーション形式を使ってください。
- `true`、`false`、`null`、配列、ループ、関数定義、`&&` / `||`、複数行コメントには対応していません。
- 関数呼び出しの引数には式を指定できます。利用できる組み込み関数以外を呼び出すと、実行時エラーになる場合があります。

スクリプトの構文エラーや実行時エラーは、**スクリプトの管理**パネル下部に表示されます。エラーを修正した後、必要に応じてグローバル変数をリセットして`init`からやり直してください。
