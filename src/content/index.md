# PhysicsLab

PhysicsLabは、円などの物体をキャンバスに配置して、重力・衝突・接続を試せるブラウザー上の物理シミュレーターです。Position Based Dynamics（PBD）を用いて物体の動きと衝突を計算します。

![スクリーンショット](../../public/docs/screenshot.png)

- [はじめ方](/docs/getting-started): 画面の見方と基本操作
- [モード](/docs/mode): 生成、充填、移動、編集、接続など
- [設定と表示](/docs/settings): 物理環境と表示・計算設定
- [ワールドとデータ管理](/docs/worlds): 保存、読み込み、画像出力
- [物体の分析](/docs/analysis): グラフとCSV出力
