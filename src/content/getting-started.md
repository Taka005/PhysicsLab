# はじめ方

PhysicsLabは、円などの物体をキャンバス上に配置し、重力や衝突、接続の動きを試せるブラウザー上の物理シミュレーターです。初回表示時にはサンプルワールドが読み込まれます。

## 画面の構成

- **キャンバス**: シミュレーションの表示と、物体の配置・編集を行います。
- **コントロールパネル**: 実行操作、物理環境、モード、選択中モードの設定を行います。
- **設定ウィンドウ**: 表示オプション、データ管理、スクリプト管理、ワールド管理を行います。

## まず動かしてみる

1. **実行**を押すとシミュレーションが始まり、ボタンは**停止**に変わります。
2. 実行中に**停止**を押すと一時停止します。
3. 停止中に**ステップ**を押すと、物理シミュレーションを1回分進めます。
4. **重力**、**摩擦**、**再生速度**を調整し、動きの変化を確認します。

実行中でもキャンバス上の物体を移動できます。シミュレーションの設定項目は[設定と表示](/docs/settings)を参照してください。

## キャンバスの操作

| 操作 | 動作 |
|---|---|
| マウスホイール | 表示を拡大・縮小 |
| `W` / `A` / `S` / `D` | 表示位置を上下左右に移動 |
| 物体上で右クリック | **分析**を開く |
| 移動モードで物体上を右クリック | 分析に加えて**接続を変更**を表示（接続済みの場合） |

ホイールによる拡大率は0.3倍から5倍です。キー操作は入力欄にフォーカスがある場合を除き、ページ全体で有効です。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | 実行 / 停止 |
| `F` | 停止中に1ステップ進める |
| `1`〜`7` | 生成、充填、移動、削除、編集、接続、切断モードに切り替える |
| `W` / `A` / `S` / `D` | 表示位置を移動 |

## 基本的な作業の流れ

1. [モード](/docs/mode)から**生成**を選び、種類と物理的な設定を決めます。
2. キャンバスをクリックして物体を配置します。直線と加速器は2点、曲線は3点を順番にクリックします。
3. 必要に応じて**編集**モードで物体を選び、プロパティを変更します。
4. **実行**または**ステップ**で動作を確認します。
5. **設定**の**データ管理**からワールドを保存したり、画像や解析データを書き出したりできます。

## リセットの違い

- コントロールパネルの**リセット**は、円などの物体だけを削除します。地面、加速器、スクリプト、物理設定は残ります。
- **設定 → データ管理 → デフォルト設定に戻す**は、物理・表示設定を初期値に戻します。ワールド内の物体やスクリプトは削除しません。
- **設定 → データ管理 → すべてリセット**は、物体、地面、加速器、トラッキング履歴を削除します。スクリプトと設定値は保持されます。

ワールドの保存・ロードやプリセットの詳細は[ワールドとデータ管理](/docs/worlds)を参照してください。
