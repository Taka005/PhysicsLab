# モード

モードを切り替えて、キャンバス上の物体を操作します。モードはコントロールパネルの**モード**メニュー、またはキーボードの`1`〜`9`で選択できます。クリック操作はキャンバス上で行います。

| キー | モード | 操作 |
|---:|---|---|
| `1` | 生成 | 物体の種類や設定を選び、クリック位置に配置します。 |
| `2` | 充填 | 長方形の対角となる2点をクリックし、その範囲に円を並べます。 |
| `3` | 移動 | 円をドラッグして動かします。地面や加速器の端点もドラッグできます。 |
| `4` | 削除 | クリック位置の物体を削除します。ドラッグで範囲を指定して一括削除できます。 |
| `5` | 編集 | クリックしたオブジェクトを選択し、パネルの設定を変更します。 |
| `6` | 接続 | 円を2つ順番にクリックして接続します。 |
| `7` | 切断 | 接続された円を2つ順番にクリックして接続を解除します。 |
| `8` | グループ | ドラッグで範囲を選び、範囲内のエンティティーをグループ化します。 |
| `9` | グループ解除 | ドラッグ範囲にグループ化されたエンティティーがあれば、グループを解除します。 |

### 生成

**生成タイプ**を選択してキャンバスをクリックします。ID欄を空にするとIDは自動で割り当てられます。任意のIDを入力するとそのIDを使用しますが、既に使用されているIDは使えません。

| 種類 | キャンバス操作 | 設定 |
|---|---|---|
| 円 | 1回クリック | 直径、質量、剛性、初速度X/Y、色、スクリプト |
| 直線 | 始点と終点をクリック | 幅、色、スクリプト |
| 曲線 | 始点、中間点、終点をクリック | 幅、色、スクリプト |
| 加速器 | 範囲の両端をクリック | 初速度X/Y、色、スクリプト |

加速器は、指定した長方形の範囲に入った円へ設定した速度を加えます。円の質量を0にすると固定され、シミュレーション中に重力や接触で動かなくなります。

### 充填

2回のクリックで長方形の対角を指定します。指定範囲を、設定した直径を間隔として円で埋めます。直径、質量、剛性、初速度、色、スクリプトを設定できます。大量の円を作る場合は範囲や直径に注意してください。

### 移動

円をドラッグすると位置を変更できます。シミュレーション実行中に動かした円は、ドラッグ中の速度がリセットされます。

直線は始点または終点、曲線は始点・中間点・終点をドラッグして形を変えます。加速器は両端をドラッグできます。端点を見つけづらい場合は、**設定 → 表示設定 → エッジを表示**を有効にしてください。

接続された円を右クリックして**接続を変更**を選ぶと、現在の距離を新しい接続距離として設定できます。

### 削除

クリック位置に重なっている円、地面、加速器を削除します。ドラッグすると表示される赤い範囲に円の中心、地面や加速器の各点が含まれるオブジェクトをまとめて削除できます。

### 編集

オブジェクトをクリックすると選択され、モード設定欄に編集可能な項目が表示されます。円では直径・質量・剛性・初速度、直線と曲線では幅、加速器では初速度を編集できます。全種類で色と割り当てるスクリプトを変更できます。

別のオブジェクトを選ぶか、他のモードへ切り替えると選択が解除されます。

### 接続と切断

接続では、接続したい円を1つずつクリックします。設定できる接続タイプは次のとおりです。

| タイプ | 接続距離 |
|---|---|
| 動的接続 | 2つの円の半径の合計。円同士が接触する距離を保ちます。 |
| 固定接続 | 接続した時点の円の中心間距離。 |

**剛性**は接続距離を保つ強さです。1に近いほど距離を維持し、低いほど伸縮しやすくなります。既に接続されている組み合わせを再接続することはできません。

切断では、解除する円を2つ順番にクリックします。2つの円の間に接続がない場合は切断されません。

### グループ

ドラッグで範囲を指定すると、その範囲内にあるエンティティーがグループ化されます。シミュレーション中はグループ内の速度が剛体運動に合わせて計算されます。範囲を選び直すと、グループは新しい範囲のエンティティーに置き換わります。

### グループ解除

ドラッグした範囲にグループ化されたエンティティーが1つでも含まれていれば、グループ全体を解除します。グループ化・解除の結果は通知で表示されます。

## グリッドへの吸着

**設定 → 表示設定 → グリッド交点設置モード**を有効にすると、生成や充填などの新しい配置位置がグリッド交点に吸着します。グリッドを表示する設定とは独立しているため、グリッド線を表示しないまま吸着だけ有効にすることもできます。グリッド間隔は表示設定で変更できます。
