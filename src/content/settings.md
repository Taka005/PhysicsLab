# 設定と表示

コントロールパネル上部のスライダーで物理環境を設定し、**設定**ウィンドウの**表示設定**タブで表示や計算のオプションを変更します。

## 物理環境

| 項目 | 初期値 | UIの範囲 | 説明 |
|---|---:|---:|---|
| 重力 | 250 | 0〜1000 | 円に作用する重力加速度です。0にすると重力がなくなります。 |
| 摩擦 | 0.001 | -0.3〜0.3 | 円の速度に作用する減衰量です。正の値は減速、負の値は加速方向に働きます。 |
| 再生速度 | 1 | 0.1〜2 | シミュレーションの進行速度です。 |

値はシミュレーションの長さなどに応じて調整してください。

## 表示設定タブ

### 表示・計算の切り替え

| 項目 | 説明 |
|---|---|
| トラッキングモード | 円の過去位置を残像として表示します。トラッキング履歴はデータ管理から削除できます。 |
| 動的トラッキングモード | 円がない場合にトラッキング履歴を消去します。円がある場合は通常どおり移動履歴を記録します。 |
| 予測モード | 現在の速度と重力から円の位置を予測して表示します。衝突や地面・接続の影響を含む予測ではありません。 |
| グリッド交点設置モード | 新たに配置する位置をグリッド交点に吸着させます。グリッド表示とは別の設定です。 |
| グリッドを表示 | キャンバスにグリッド線を表示します。 |
| ベクトルを表示 | 円の速度ベクトルを表示します。 |
| 接続を表示 | 円同士の接続線を表示します。 |
| エッジを表示 | 直線・曲線・加速器の編集用端点を表示します。 |
| 角度計を表示 | キャンバス上にドラッグ可能な角度計を表示します。 |
| 物体を非表示 | 円を隠します。物理計算や操作対象からは削除されません。 |
| エフェクトを非表示 | 加速器を隠します。 |
| 地面を非表示 | 直線・曲線を隠します。 |
| スクリプトを無効化 | シミュレーション中のスクリプト実行を停止します。 |
| デバッグモード | FPS、カーソルの座標、オブジェクト数、カーソル位置のオブジェクト情報を表示します。 |

### 数値設定

| 項目 | 初期値 | UIの範囲 | 説明 |
|---|---:|---:|---|
| グリッド間隔 | 50 | 5〜100（5刻み） | グリッド線の間隔と、グリッド吸着位置の間隔です。 |
| トラッキング間隔 | 100 ms | 100〜3000 ms | トラッキング履歴を記録する時間間隔です。 |
| 最大トラッキング数 | 100 | 10〜1000 | 保持するトラッキング履歴数の上限です。 |
| 最大予測数 | 20 | 1〜50 | 予測モードで各円について表示する予測点数です。 |
| スクリプト実行間隔 | 100 ms | 10〜1000 ms | スクリプトを実行するシミュレーション時間間隔です。 |
| ワールドサイズ | 5000 | 1000〜10000 | 円がこの境界を越えるとワールドから削除されます。 |
| PPS | 120 | 30〜300 | 物理計算のステップ数（1秒あたり）です。 |

## 設定の初期化

**設定 → データ管理 → デフォルト設定に戻す**で、物理環境、表示位置、ズーム、上記の各数値設定、および表示切り替えを初期状態に戻します。ワールドのオブジェクトとスクリプトは削除されません。
